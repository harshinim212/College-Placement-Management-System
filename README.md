# 🎓 College Placement Management System

## 📌 About the Project

The **College Placement Management System** is a simple web-based project developed to provide students with information about campus placements and job opportunities.

The project allows students to explore recruiting companies, view placement drive details, and access a student registration form.

## 🎯 Objectives

* To provide placement-related information to students.
* To display details of recruiting companies.
* To provide a student registration form.
* To display placement drive information.
* To make placement details easy to access.

## 🛠️ Technologies Used

* **HTML** – To create the structure of web pages.
* **CSS** – To design and style the web pages.
* **JavaScript** – To handle basic form interactions.

## 📂 Project Modules

| Module               | Description                                         |
| -------------------- | --------------------------------------------------- |
| Home Page            | Displays project introduction and objectives.       |
| Student Login        | Provides a basic login form interface.              |
| Student Registration | Collects student details through a form.            |
| Company Details      | Displays recruiting companies and job roles.        |
| Placement Drives     | Shows placement drive schedules and sample results. |

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in a web browser such as Google Chrome.
5. Use the navigation links to explore the different pages.

## 💡 Features

* Simple and user-friendly interface.
* Navigation between different web pages.
* Student registration form.
* Recruiting company details.
* Placement drive information.
* Basic form interactions using JavaScript.
